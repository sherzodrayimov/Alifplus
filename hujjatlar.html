Maxfiylik siyosati

Alif+ sizning maxfiyligingizni to'liq himoya qiladi. Barcha matn va hujjatlar (.docx, .pdf, .txt) faqat o'z brauzeringiz ichida qayta ishlanadi — hech qanday ma'lumot tashqi serverlarga yuborilmaydi va saqlanmaydi.

Yangi alifboda nimalar o'zgardi?

Yangi o'zbek lotin alifbosida faqat 4 ta harf yangi ko'rinishga o'tdi (ng birikmasi o'zgarmagan). Alif+ esa eski usulda yozganingizda ularni avtomatik yangisiga o'giradi:

● Alif+ jonli namoyish
|
Eski alifboda yozilmoqda...
O + ' → Ö

Harflarni yozish usullari

Yangi alifbodagi O', G', Sh, Ch harflarini kompyuter va telefonda eng oson yozishning 3 ta usuli:

1-usul · Tavsiya etiladi Kompyuterda avtomatik (Alif+ dasturi)

macOS yoki Windows ilovasini o'rnatsangiz, istalgan dasturda (Telegram, Word, brauzer) oddiy klaviaturada yozaverasiz:

o' → ö g' → ğ sh → ş ch → ç
Yoqish/o'chirish: Ctrl + Shift · Bekor qilish: ⌫ Yuklab olish →
2-usul · Telefon iPhone va Android klaviaturasida

Harf tugmasini bosib turing — qo'shimcha harflar menyusidan keraklisini tanlang:

O bosib turing → Ö S bosib turing → Ş C bosib turing → Ç G (Turkcha klaviatura) → Ğ
3-usul · Sinab ko'rish Shu yerning o'zida yozib ko'ring yoki nusxa oling

macOS · O‘rnatish qo‘llanmasi

Alif+ klaviaturasini macOS’ga o‘rnatish

1
Dasturni yuklab oling

«Kompyuter uchun yuklab olish» bo‘limidan macOS uchun faylni yuklab oling.

2
Applications papkasiga ko‘chiring

Faylni ochib, Alif+ ilovasini Applications papkasiga tashlang.

3
Gatekeeper ruxsati

System Settings → Privacy & Security bo‘limidan «Open Anyway» tugmasini bosing.

4
Accessibility (Klaviatura) ruxsati

Privacy & Security → Accessibility ro‘yxatida Alif+ ni yoqing — shundan so‘ng o', g', sh, ch avtomatik o', g', sh, ch ga aylanadi.
