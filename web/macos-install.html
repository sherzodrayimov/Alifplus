macOS uchun Alif+ (v2.0 Universal)

Apple Silicon (M1, M2, M3, M4) va Intel protsessorli barça Mac kompyuterlarida işlaydi.

1
Ilovani Applications papkasiga köçiring
Yuklab olingan AlifPlus-2.0-macOS.dmg faylini oçing va Alif+.app belgisini Applications papkasiga torting.
2
Agar macOS “oçib bölmaydi” deb ogohlantirsa (Gatekeeper):
Ilova ustiga siçqonçaning öng tugmasini bosing → Open (Открыть) ni tanlang yoki Terminalda quyidagi buyruqni bir marta bajaring:
xattr -cr /Applications/Alif+.app && open /Applications/Alif+.app
3
Accessibility (Universal kiriş) ruxsatini yoqing
Real vaqtda harflarni özgartiriş uchun: System Settings → Privacy & Security → Accessibility bölimida Alif+ tugmasini yoqing.

Qanday işlatiladi?

1) Yozişdan oldin Ctrl + Shift ni bosing — dastur YOQILADI (yuqori menyu satrida A+ belgisi yonadi).
2) Yozing: shahar → şahar, o'zbek → özbek, O' → Ö, Sh → Ş, Ch → Ç.
3) Kerak bölsa DARHOL Delete (⌫) bosing — asl holi qaytadi (ş → sh).
4) Sozlamalar — yuqori menyu satridagi A+ belgisini bosing.
