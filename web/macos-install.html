macOS uchun Alif+ (v2.0 Universal)

Apple Silicon (M1, M2, M3, M4) va Intel protsessorli barcha Mac kompyuterlarida ishlaydi.

1
Ilovani Applications papkasiga ko‘chiring
Yuklab olingan AlifPlus-2.0-macOS.dmg faylini oching va Alif+.app belgisini Applications papkasiga torting.
2
Agar macOS “ochib bo‘lmaydi” deb ogohlantirsa (Gatekeeper):
Ilova ustiga sichqonchaning o‘ng tugmasini bosing → Open (Открыть) ni tanlang yoki Terminalda quyidagi buyruqni bir marta bajaring:
xattr -cr /Applications/Alif+.app && open /Applications/Alif+.app
3
Accessibility (Universal kirish) ruxsatini yoqing
Real vaqtda harflarni o‘zgartirish uchun: System Settings → Privacy & Security → Accessibility bo‘limida Alif+ tugmasini yoqing.

Qanday ishlatiladi?

1) Yozishdan oldin Ctrl + Shift ni bosing — dastur YOQILADI (yuqori menyu satrida A+ belgisi yonadi).
2) Yozing: shahar → şahar, o'zbek → özbek, O' → Ö, Sh → Ş, Ch → Ç.
3) Kerak bo‘lsa DARHOL Delete (⌫) bosing — asl holi qaytadi (ş → sh).
4) Sozlamalar — yuqori menyu satridagi A+ belgisini bosing.
