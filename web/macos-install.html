Alif+ 1.2.0macOS 12 va yangiroqApple Silicon + Intel
Boshlashdan oldin

Internet faylni yuklash uchun kerak. O‘rnatish va yozish internet talab qilmaydi. Nusxalash sizning foydalanuvchi hisobingizda bajariladi; tizim ruxsatlarini tasdiqlashda Mac paroli yoki Touch ID so‘ralishi mumkin.

Bu nusxa ad-hoc imzoli va Apple notarizatsiyasidan o‘tmagan. Birinchi ochishda noma’lum ishlab chiquvchi haqida ogohlantirish chiqishi mumkin. Quyidagi “Open Anyway” bosqichini faqat o‘zingiz ishongan Alif+ nusxasi uchun bajaring.

  1. DMG faylini yuklab oling

    Alif+ saytida macOS uchun yuklab olish tugmasini bosing. Fayl nomi: AlifPlus-1.2.0.dmg. Odatda u Downloads / Yuklamalar papkasiga tushadi.

    Rasmiy GitHub Releases sahifasi orqali ham faylni topish mumkin. Agar shu DMG allaqachon ochilgan bo‘lsa, keyingi bosqichga o‘ting.

  2. DMG’ni oching

    AlifPlus-1.2.0.dmg ustiga ikki marta bosing. Finder’da Alif+ 1.2.0 diski ochiladi; u yon paneldagi Locations ichida ham ko‘rinadi.

    Ichida klaviatura, yordamchi ilova, O'rnatish (1-klik).command va ushbu yo‘riqnoma bor. Yordamchi ilovani shu disk ichidan alohida ishga tushirmang; keyingi bosqich uni doimiy joyiga o‘rnatadi.

  3. O‘rnatuvchini ishga tushiring

    O'rnatish (1-klik).command ustiga ikki marta bosing. Terminal oynasining ochilishi odatiy — skript nusxalash natijasini shu yerga yozadi.

    Agar noma’lum ishlab chiquvchi yoki tekshirib bo‘lmaydigan dastur haqida ogohlantirish chiqsa, avval oynani yoping, keyin Apple  → System Settings → Privacy & Security → Security → Open Anyway orqali aynan Alif+ faylini tasdiqlang. So‘ralsa, Open ni bosing va skriptni qayta oching.

    Terminal aynan o‘rnatish diskidagi fayllarni o‘qishga ruxsat so‘rasa, shu diskka kirishni tasdiqlang. Oynada Alif+ o‘rnatildi xabarini kuting. Nusxalash uchun sudo yoki Terminalga qo‘shimcha buyruq yozish talab qilinmaydi.

    macOS 12: Security & Privacy sozlamalari System Preferences ichida. Ogohlantirishdagi fayl buzilgani yoki zararli dastur haqida xabar oddiy noma’lum ishlab chiquvchi ogohlantirishidan farq qiladi; bunday holatda qayta yuklab oling va ishlab chiquvchiga xabar bering.

  4. Avto-o‘girishga Accessibility ruxsatini bering

    Yordamchi ilova ochilgach, Open System Settings so‘rovi chiqishi mumkin. System Settings → Privacy & Security → Accessibility ichida Alif+ Avto-O'girish yonidagi ruxsatni yoqing.

    Ro‘yxatda yo‘q bo‘lsa: + → ⌘⇧G → ~/Applications ni kiriting → Alif+ Avto-O'girish.app → Open. Aynan o‘rnatilgan nusxani tanlang.

    Ilova o‘rnatilgan joy: ~/Applications/Alif+ Avto-O'girish.app. Ruxsat aniqlangach, menyu satridagi ÖZ — Ruxsat kerak holati Pauza holatiga o‘tadi.

    macOS 12: System Preferences → Security & Privacy → Privacy → Accessibility; o‘zgartirish uchun qulfni ochish talab qilinishi mumkin. Faqat klaviatura terilmasidan foydalansangiz, yordamchi ruxsatisiz ham maxsus harflarni tugmalar orqali yozish mumkin.

  5. Alif+ klaviaturasini tizimga qo‘shing

    System Settings → Keyboard → Text Input → Edit → + yo‘lini oching. Uzbek yoki Others bo‘limidan Alif+ ni toping va Add ni bosing.

    Klaviatura nusxasi ~/Library/Keyboard Layouts/Alif+.bundle ichida. Agar Alif+ hali ko‘rinmasa, ochiq ishlaringizni saqlang, Apple  menyusidan Log Out qiling va hisobga qayta kiring. So‘ng klaviaturani qo‘shishni yana bajaring.

    macOS 12: System Preferences → Keyboard → Input Sources → +.

  6. Klaviaturani tanlang va tekshiring

    Asl [ ] ; ' belgilarini Option ⌥ + shu tugma orqali yozasiz. QWERTY harflari odatdagi joyida qoladi.

  7. Ctrl+Shift bilan avto-o‘girishni yoqing

    Yordamchi har ishga tushganda pauzada turadi. Ctrl + Shift ni birga bosing va qo‘yib yuboring. Yuqori menyu satrida ÖZ ⇄ Faol chiqishi kerak.

    shahar → şahar, o'zbek → özbek, O' → Ö, Sh/SH → Ş, Ch/CH → Ç.

    Masalan, sh yozib ş chiqqach, darhol Delete / ⌫ yoki Backspace bosing — asl sh qaytadi. Keyingi harf, bosish yoki kursor harakatidan so‘ng Delete odatdagidek ishlaydi.

    Yana Ctrl+Shift — pauza. Inglizcha yoki kod yozayotganda shu orqali pauzaga qo‘yish mumkin. Secure Input vaqtida va xavfsizligi aniqlanmagan maydonlarda avto-o‘girish to‘xtaydi.

  8. Avtomatik ishga tushirish va yakunlash

    macOS 13+ da ÖZ menyusi → Kompyuterga kirganda ishga tushirish bandini ixtiyoriy yoqing. macOS 12 da yordamchini keyingi safar ~/Applications ichidan qo‘lda oching.

    Klaviatura qo‘shilgan va yordamchi o‘rnatilganidan keyin Finder’dan Alif+ 1.2.0 → Eject ni bosing. Yuklangan DMG’ni saqlash yoki o‘chirish o‘rnatilgan nusxaga ta’sir qilmaydi.

Biror bosqich ishlamasa

DMG ochilmayapti yoki “image not recognised” chiqdi

Fayl to‘liq yuklanganini tekshiring va rasmiy manbadan qayta yuklang. Yuklangan fayl HTML xato sahifasi emas, .dmg ekaniga ishonch hosil qiling. macOS versiyasi 12 yoki yangiroq bo‘lishi kerak.

Open Anyway tugmasi chiqmayapti

Avval bloklangan faylni bir marta ochishga urinib ko‘ring, keyin Privacy & Security oynasini qayta oching. Apple bu tugma urinishdan keyin taxminan bir soat ko‘rinishini qayd etadi. Tashkilot boshqaradigan Mac’da bu imkoniyat administrator siyosati bilan yopilgan bo‘lishi mumkin.

Skript ishga tushmadi yoki o‘rnatish xato bilan tugadi

DMG ichidagi O'rnatish (1-klik).command ni Finder orqali oching. Skript terminalida “O‘rnatish tugamadi” chiqsa, undan keyingi aniq xabarni saqlang. To‘liq yuklangan DMG’dan qayta urinib ko‘ring. O‘rnatish muvaffaqiyatli tugamagan bo‘lsa, keyingi bosqichlarga o‘tmang.

Klaviatura ro‘yxatda yo‘q yoki ikkita Alif+ bor

Ishlaringizni saqlab, hisobdan chiqing va qayta kiring; Uzbek va Others bo‘limlarini tekshiring. Eski umumiy nusxa /Library/Keyboard Layouts/Alif+.bundle ichida qolgan bo‘lishi mumkin; yangi nusxa esa ~/Library/Keyboard Layouts ichida. Dublikatni olib tashlashda boshqa klaviaturalarga tegmang.

“Ruxsat kerak” holati ketmayapti

Accessibility ro‘yxatida DMG’dagi yoki eski /Applications nusxasini emas, ~/Applications ichidagi yangi ilovani tanlang. Yangilashdan keyin eski yozuvni ro‘yxatdan olib tashlab, o‘rnatilgan ilovani qayta qo‘shish va ruxsatni yoqish talab qilinishi mumkin. So‘ng yordamchini qayta oching.

Klaviatura ishlayapti, lekin sh/o' o‘girilmayapti

ÖZ menyusidan yordamchi ochilganini, Accessibility ruxsatini va Ctrl+Shift’dan keyingi “Faol” holatini tekshiring. Avval TextEdit’da oddiy matn bilan sinang. Maxsus muharrir, parol yoki Secure Input maydonida avtomatik o‘girish pauza qilishi mumkin; bu vaqtda maxsus harflarni klaviatura tugmalari bilan yozing.

Yangilash va eski nusxalarni olib tashlash

Yangi DMG’dan o‘rnatuvchini ishga tushiring. Skript avval yangi nusxani to‘liq tayyorlaydi, yordamchini to‘xtatadi va oldingi foydalanuvchi nusxasini .previous nomida saqlaydi. Eski ilova /Applications ichida qolgan bo‘lsa, qaysi nusxa ishlayotganini tekshiring. Yangilashdan keyin Accessibility ruxsatini qayta qo‘shish kerak bo‘lishi mumkin.

Alif+ ni butunlay olib tashlash

ÖZ menyusida avtomatik ishga tushirishni o‘chiring va Chiqish ni bosing. Keyboard input sources ro‘yxatidan Alif+ ni olib tashlang. Finder’da ⌘⇧G orqali ~/Applications va ~/Library/Keyboard Layouts ni ochib, faqat Alif+ komponentlari hamda keraksiz .previous nusxalarini olib tashlang. Accessibility ro‘yxatidagi yozuvini ham o‘chiring, so‘ng hisobdan chiqib qayta kiring.
