Maxfiylik siyosati

Alif+ sizning maxfiyligingizni töliq himoya qiladi. Barça matn va hujjatlar (.docx, .pdf, .txt) faqat öz brauzeringiz içida qayta işlanadi — heç qanday ma'lumot taşqi serverlarga yuborilmaydi va saqlanmaydi.

Yangi alifboda nimalar özgardi?

Harflarni yoziş usullari

Yangi alifbodagi Ö, Ğ, Ş, Ç harflarini kompyuter va telefonda eng oson yozişning 3 ta usuli:

1-usul · Tavsiya etiladi Kompyuterda avtomatik (Alif+ dasturi)

macOS yoki Windows ilovasini örnatsangiz, istalgan dasturda (Telegram, Word, brauzer) oddiy klaviaturada yozaverasiz:

o' → ö g' → ğ sh → ş ch → ç
Yoqiş/öçiriş: Ctrl + Shift · Bekor qiliş: ⌫ Yuklab oliş →
2-usul · Telefon iPhone va Android klaviaturasida

Harf tugmasini bosib turing — qöşimça harflar menyusidan keraklisini tanlang:

O bosib turing → Ö S bosib turing → Ş C bosib turing → Ç G (Turkça klaviatura) → Ğ
3-usul · Sinab köriş Şu yerning özida yozib köring yoki nusxa oling

macOS · O‘rnatish qo‘llanmasi

Alif+ klaviaturasini macOS’ga o‘rnatish

1
Dasturni yuklab oling

«Kompyuter uçun yuklab oliş» bo‘limidan macOS uchun faylni yuklab oling.

2
Applications papkasiga ko‘chiring

Faylni ochib, Alif+ ilovasini Applications papkasiga tashlang.

3
Gatekeeper ruxsati

System Settings → Privacy & Security bo‘limidan «Open Anyway» tugmasini bosing.

4
Accessibility (Klaviatura) ruxsati

Privacy & Security → Accessibility ro‘yxatida Alif+ ni yoqing — shundan so‘ng o', g', sh, ch avtomatik ö, ğ, ş, ç ga aylanadi.
