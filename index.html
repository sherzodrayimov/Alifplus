O‘rnatish yo‘riqnomasi

Ikkala tizimda ham klaviatura terilmasi va real-vaqt avto-o‘girish yordamchisi birga o‘rnatiladi.

🍎 macOS uchun o‘rnatish

  • 1
    AlifPlus-1.1.0.dmg faylini yuklab oling va ikki marta bosib oching.
  • 2
    Alif+.bundle faylini shu oynadagi Keyboard Layouts jildi ustiga sudrab tashlang (yoki O'rnatish (1-klik).command ni ishga tushiring).
  • 3
    System Settings → Keyboard → Text Input → Edit → + tugmasini bosib Uzbek → Alif+ ni qo‘shing.
  • 4
    Avto-o‘girish uchun Alif+ Avto-O'girish.app dasturini Applications ga ko‘chiring (yuqori panelda ÖZ⇄ belgisi chiqadi).

🪟 Windows 10 / 11 uchun o‘rnatish

  • 1
    AlifPlus-1.1.0-Setup.exe o‘rnatuvchisini yuklab oling va ishga tushiring.
  • 2
    Agar Windows SmartScreen oynasi chiqsa, More info → Run anyway tugmasini bosing.
  • 3
    O‘rnatuvchi klaviatura drayverini (kbdalif.dll) va Avto-o‘girish yordamchisini avtomatik sozlaydi.
  • 4
    Win + Space tugmalari orqali O‘zbekcha (Alif+) terilmasiga o‘ting va yozishni boshlang.
